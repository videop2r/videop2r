# VIDEOP2R: Video Understanding from Perception to Reasoning

### [Paper](https://arxiv.org/pdf/2511.11113) | [arXiv](https://arxiv.org/abs/2511.11113) | [Project Page](https://videop2r.github.io/videop2r/)

**CVPR Findings 2026**

Yifan Jiang, Yueying Wang, Rui Zhao, Toufiq Parag, Zhimin Chen, Zhenyu Liao, Jayakrishnan Unnikrishnan

**VIDEOP2R** is a process-aware video reinforcement fine-tuning (RFT) framework that enhances video reasoning by modeling perception and reasoning as distinct processes. We introduce:

- **VIDEOP2R-CoT-162K**: A high-quality, process-aware chain-of-thought dataset built via a three-step generation pipeline.
- **PA-GRPO**: A process-aware RL algorithm that provides separate rewards for perception and reasoning.

VIDEOP2R achieves state-of-the-art performance on **6 out of 7** video reasoning and understanding benchmarks.
